Para usar la app necesitas una cuenta gratis de Firebase (la base de datos en la nube de Google). Sigue estos pasos:

1. Ve a console.firebase.google.com y crea un proyecto (puede llamarse "RifaPROMUF").
2. En el panel del proyecto, haz click en el ícono Realtime Database y luego "Crear base de datos". Elige tu región y acepta.
3. En la pestaña Reglas de la base de datos, reemplaza todo con:
{ "rules": { ".read": true, ".write": true } }
y haz click en Publicar.
4. Ve a Configuración (ícono de engranaje) > Tus apps > añade una app Web (ícono </>).
5. Copia todo el objeto firebaseConfig que te muestra Google y pégalo aquí abajo.
Tus datos se guardan localmente en el navegador y se sincronizan con Firebase. Nadie más puede modificar tu configuración.
